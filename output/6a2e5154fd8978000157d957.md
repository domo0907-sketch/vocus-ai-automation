# 貓咪每日餵食量科學計算指南：依年齡與體重精準調整營養

**摘要**  
餵食貓咪的份量不該憑直覺，而應依據年齡、體重及結紮狀況進行科學計算。本文透過基礎代謝率（RER）與每日總能量需求（DER）兩大公式，針對幼貓、成貓及高齡貓三種常見狀況提供具體範例，並教你如何閱讀寵物食品包裝上的熱量資訊，避開常見餵食誤區，確保主子健康均衡飲食。

**關鍵字**  
貓咪餵食量、貓咪熱量需求、幼貓營養、成貓餵食、老貓熱量計算

---

## 一、貓咪熱量需求的基本計算

### 1. RER：基礎代謝率（Resting Energy Requirement）

RER 是指貓咪在完全靜止、無任何活動下維持生命基本功能（呼吸、心跳、器官運作）所需的最低熱量。成貓（體重2至20公斤）可採用簡化公式計算：

```
RER = (體重 kg × 30) + 70
```

醫學上針對過胖或過瘦個體會使用更精細指數：

```
RER = 70 × (體重 kg) ^ 0.75
```

### 2. DER：每日總熱量需求（Daily Energy Requirement）

實際光靠RER不夠，因為活動量、年齡、結紮情況都會影響每日所需熱量。為此須將RER乘以「需求因子（X）」，得出DER：

```
DER = RER × X
```

需求因子 X 根據貓咪狀態不同而異，例如幼貓、成貓、已結紮或是高齡等階段皆不同。

## 二、年齡與體重三大實例計算

### 範例 A：3 個月大、體重 1.5公斤幼貓

幼貓生長快速，需要高熱量維持發育。  
RER 計算:

```
1.5 × 30 + 70 = 115 kcal
```

以需求因子3.0計算DER：

```
115 × 3.0 = 345 kcal/日
```

若使用每罐80克、熱量90 kcal的主食罐：

```
345 ÷ 90 ≈ 3.8 罐/日
```

建議分作4至5餐少量多餐。

### 範例 B：2 歲、已結紮、體重5公斤成貓

活動量穩定，需求較幼貓低。  
RER 計算：

```
5 × 30 + 70 = 220 kcal
```

已結紮成貓需求因子約為1.2，故DER為：

```
220 × 1.2 = 264 kcal/日
```

以半濕食搭配乾糧，晚餐給予100 kcal主食罐，白天補足164 kcal乾糧。  
飼料若標示熱量4000 kcal/kg（約4 kcal/g），則乾糧份量為：

```
164 ÷ 4 = 41 克
```

### 範例 C：8 歲、已結紮、體重4.5公斤高齡貓

代謝減慢，需要控制熱量避免肥胖。  
RER 計算：

```
4.5 × 30 + 70 = 205 kcal
```

需求因子約為1.0，DER為：

```
205 × 1.0 = 205 kcal/日
```

主食罐95 kcal/罐，則建議：

```
205 ÷ 95 ≈ 2.1 罐/日
```

## 三、如何依寵物食品包裝精準換算餵食量

- 主食罐或副食罐通常標示每罐或每100克含多少大卡（kcal）。  
- 乾糧通常標示為每公斤熱量（kcal/kg），請除以1000換算成每克熱量（kcal/g）。

**計算公式：**

```
每日應餵食乾糧克數 = DER ÷ 每克飼料熱量
```

## 四、避免三大常見餵食誤區

1. **以「米杯」量飼料**  
飼料顆粒大小、密度不一，用米杯量會誤差很大。建議購買電子廚房秤，精準以克數計量。

2. **乾飼料任食制**  
除了幼貓，任食制極易導致肥胖、飼料氧化甚至挑食。建議定時定量。

3. **忽略點心熱量**  
零食熱量不能超過每日總熱量的10%，若餵點心須從正餐熱量中扣除。

## 五、結語：動手計算，守護愛貓健康

貓咪體態是健康指標，建議每兩週量體重一次，依照實際情況微調餵食量（增加或減少5%-10%）。透過科學計算的餵食方法，能幫助你的愛貓維持理想體態與活力，減少肥胖、代謝疾病風險。快掌握公式，計算屬於主子的完美餐盤吧！
